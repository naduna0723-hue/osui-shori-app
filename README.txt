汚水処理特論 10年分 v14 - iPhone / PWA版

【iPhoneで使う方法】
1. このフォルダの中身を GitHub Pages など HTTPS のWebサーバーへアップロードします。
2. iPhoneのSafariで公開URLを開きます。
3. Safariの共有ボタン →「ホーム画面に追加」を選びます。
4. 追加後はホーム画面のアイコンから起動できます。

※以前のv10等を同じGitHub Pages URLで公開していた場合は、ファイル一式をv14へ置き換えてください。
※更新が反映されない場合はSafariでページを再読み込み後、ホーム画面から再起動してください。
